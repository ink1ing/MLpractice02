# FCN 模型实现总结

## 实现内容

我们为玉米锈病识别与预测任务实现了一个完整的FCN（全卷积网络）模型解决方案，具体包括：

1. **模型架构设计**：
   - 在 `model.py` 中新增了 `FCNBackbone`、`AttentionGate` 和 `DiseaseFCN` 类
   - 采用编码器-解码器结构，包含四层编码和四层解码，带跳跃连接
   - 添加了注意力门控机制，提高对关键区域的关注度
   - 设计了双输出头：分割头(位置分类)和回归头(等级预测)

2. **训练脚本**：
   - 创建了专门的 `run_fcn.py` 训练脚本
   - 实现了混合精度训练，提高训练效率
   - 加入了早停策略，避免过拟合
   - 支持多种监控指标(F1或MAE)，保存最佳模型

3. **可视化工具**：
   - 实现了 `visualize_fcn.py` 可视化脚本
   - 支持分割结果可视化
   - 支持注意力图可视化
   - 提供叠加显示，增强解释性

4. **启动脚本**：
   - 创建了 `train_fcn.sh` 启动脚本（Windows下需改为.bat或直接使用Python命令）
   - 自动记录训练日志
   - 包含训练后自动可视化步骤

5. **文档更新**：
   - 在 `README.md` 中添加了FCN模型部分
   - 提供了详细的模型架构说明
   - 提供了使用方法和参数建议

## 使用方法

### Windows系统使用说明

由于您使用的是Windows系统，请按以下步骤使用FCN模型：

1. **训练FCN模型**：
   ```
   python run_fcn.py --data_root ./guanceng-bit --json_root ./biaozhu_json --output_dir ./output_fcn --batch_size 8 --learning_rate 0.0001 --epochs 50 --monitor_metric f1 --patience 5
   ```

2. **可视化FCN结果**：
   ```
   python visualize_fcn.py --data_root ./guanceng-bit --json_root ./biaozhu_json --model_path ./output_fcn/best_model.pth --output_dir ./fcn_visualization
   ```

3. **如需同时记录日志**，可以创建一个批处理文件(train_fcn.bat)，内容如下：
   ```
   @echo off
   echo 开始FCN模型训练
   python run_fcn.py --data_root ./guanceng-bit --json_root ./biaozhu_json --output_dir ./output_fcn --batch_size 8 --learning_rate 0.0001 --epochs 50 > fcn_training.log 2>&1
   echo 训练完成，日志保存在fcn_training.log
   ```

### 模型性能优化建议

1. **批次大小**：
   - GPU训练：使用8或16的批次大小
   - CPU训练：使用4的批次大小

2. **学习率**：
   - 初始学习率设为0.0001
   - 使用ReduceLROnPlateau策略自动调整

3. **训练轮数**：
   - 设置为50-60轮
   - 配合早停策略，一般在30-40轮达到最优

4. **任务权重**：
   - 默认位置任务权重0.7，等级任务权重0.3
   - 可以尝试0.6/0.4或0.8/0.2进行调优

5. **数据增强**：
   - 默认使用水平翻转、垂直翻转和随机旋转
   - 可以考虑增加颜色抖动增强鲁棒性

## 优势与创新点

1. **FCN架构优势**：
   - 相比CNN和ResNet，FCN能够捕获更精细的空间信息
   - 通过像素级分类，能够确定病害的准确位置和范围
   - 跳跃连接有效保留多分辨率特征，提高识别准确度

2. **注意力机制优势**：
   - 自动聚焦于病害区域，减少背景干扰
   - 提高对轻微病害的检测敏感性
   - 增强模型对复杂场景的适应能力

3. **可解释性增强**：
   - 分割图直观展示病害分布
   - 注意力图揭示模型决策依据
   - 便于专家审查和理解模型行为

4. **工程化改进**：
   - 混合精度训练提高训练速度
   - 早停策略避免过拟合
   - 完整的可视化工具链
